# Macカメラ動作確認UI

Macのブラウザでカメラ画像を共通Workerへ送り、スマホ保持・5秒の継続判定・通知を確認するための簡易UIです。製品用のWeb画面とは別に使えます。

## 起動

リポジトリ直下の `cloudflare/.env.connection` に次の接続設定を置きます。このファイルはGit管理対象外です。実際のトークンはチームの共有経路で受け取ってください。

```dotenv
FOCUS_API_URL=https://focus-shared-api-20261018.take-otani.workers.dev
FOCUS_API_TOKEN=replace-with-worker-token
```

```sh
npm run start:mac-check
```

表示された `http://127.0.0.1:3000` をChromeまたはSafariで開きます。ポートが使用中なら `MAC_CAMERA_PORT=3001 npm run start:mac-check` で変更できます。

1. 画面の開始ボタンを押し、ブラウザのカメラ許可を選びます。
2. カメラに手元を映し、スマホを持たない状態と持つ状態を比べます。
3. 新しい画像で5秒以上の継続保持が確認されると、画面に通知が出ます。音は画面で切り替えられます。
4. 一時停止・終了でカメラと撮影を止めます。別タブへの移動など画面が非表示になった場合も停止します。

既定のセッションは3分で終了します。カメラは開始操作まで有効になりません。カメラ許可が拒否された場合は、ブラウザのサイト設定とmacOSの「システム設定 → プライバシーとセキュリティ → カメラ」で使用ブラウザを確認してください。

## 見る項目

- 保持確率：画像内でスマホを手に持っているか。
- 可視性：手元を判定できる状態か。
- 継続時間：APIが新しい画像から確認した保持時間。画面のタイマーだけで通知しません。
- 応答時間とフレーム数：画像送信から応答までの時間と受理した応答数。
- 判定理由・ログ：不可視、API失敗、クールダウンなどの確認用。

通知後は60秒のクールダウンがあります。画像の受理間隔が2.5秒を超えると継続時間はリセットされます。通信や推論の時間により、現実に持った瞬間から正確に5秒で通知される保証はありません。

## 接続と保存

カメラ画像はMac上のローカルサーバーを経由し、Cloudflare WorkerとOpenAIへ送信されます。UIとローカルサーバーは画像をファイルに保存しません。サーバーは `127.0.0.1` だけで待ち受け、公開サーバーとしては使いません。

Workerの `FOCUS_API_TOKEN` はローカルサーバーが保持し、ブラウザへ渡しません。`OPENAI_API_KEY` はCloudflareのSecretだけに設定します。ブラウザの保存領域へキーを保存する処理はありません。

```sh
npm run test:mac-check
```

ローカルプロキシの接続制限・秘密値の扱い・送信上限などを検証できます。
