# 共通API接続（2026-10-18）

ユーザー提供の「API仕様書.md」（Cloudflare Worker版）に合わせ、直接Decisions接続から切り替えた。
接続先は `https://focus-shared-api-20261018.take-otani.workers.dev`。
共有トークンの実値はコード・資料に含めない。

- `POST /v1/sessions`: `device_type: reachy_mini`, `duration_seconds`。Bearer認証。
- `POST /v1/sessions/{id}/frames`: 生JPEG、Content-Type image/jpeg、一意のX-Frame-Id、1MiB以下。
- `POST /v1/sessions/{id}/control`: pause/resume/end。通知は実行しない。
- スマホ保持5秒、可視性・保持しきい値、クールダウンはサーバー側が管理する。
- 本体はnext_capture_after_msだけに従い、独自の3回連続やローカル保持タイマーを持たない。
- 新しいフレーム応答のnotifyだけを通知IDごとに一度消費。表示用状態にはnotifyを保存しない。
- API設定やトークンを変えると、本体を先に停止し、旧接続情報で旧セッションの終了を要求する。
- API待ちでもローカル停止・期限終了を優先する。遅いstart成功も停止後なら即終了する。
- ネットワーク切断等でサーバー終了に失敗しても本体は停止し、サーバー側期限で終了する。

公開サーバーの`/health`はprovider/configuredを返す。configured=trueでも実画像の認識精度・
モデル権限・残高・推論遅延の検証は別途必要。

## 動作の追加指示

アプリ中は待機時も小さな呼吸・アンテナ動作を続ける。モーションのチェックボックスは提供しない。
通知時は本体にある公式fear1（😨）の記録済み軌跡と付属音を使い、音の終了後に「スマホ、今すぐ置いて！」と話す。停止操作でリアクションを取り消し、
アプリ終了で待機動作も止める。起動時はモーター有効化後、2秒でカメラを標準姿勢へ上げる。

## クールダウン撤去とスマホを置いた反応

`api/src/engine.mjs` はReachyのみクールダウン0秒に変更。公開WorkerへのデプロイはAPI担当者へ依頼中であり、未反映のAPIは60秒間撮影を止める。新しい通知には引き続き新たな5秒間の確認が必要。

本体は可視性0.7以上・スマホ確率0.8以上を受けた後、新しい `phone_use_not_detected` 応答が可視性0.7以上・スマホ確率0.2以下なら `cheerful1` を1回再生する。非検出が続いても繰り返さず、新たな保持→非検出で再び喜ぶ。停止・設定変更・世代変更で記憶をリセットする。
