# Reachy Mini単体の集中支援アプリと共有リポジトリからの直接配布

## 目的・参照

Reachy Mini Wireless単体でスマホ閲覧・操作を検出し、穏やかな声かけと任意の小さな動作で気づきを促す。
仕様書: https://focus-team-spec-20261018-a14d.donald-25.chatgpt.site/
ブランチ: `codex/reachy-mini-focus`

## 承認済みの変更

共通バックエンドを使わず、本体からDecisions APIへ直接接続する。
利用者のキーは本体に保存し、コードへ含めない。
共有リポジトリのルートを公式Pythonアプリ形式にし、GitHubとHF Spaceへ同一コミットを直接pushする。
Pythonパッケージは `reachy_focus` のみに限定する。
共通API/他機器の5秒保持ルールは変更しない。

## 実装と完了条件

- [x] Web UI: キー設定、カメラ確認、通知テスト、開始/一時停止/再開/終了
- [x] 本体25分タイマー、約3秒間隔、長辺640px以下、同時API要求1件
- [x] 判断可能かつスマホ操作確率0.8以上を3回連続で通知、60秒クールダウン
- [x] 非検出/判定不能/通信失敗/設定変更/停止/有効結果間隔10秒以上でリセット
- [x] 停止後の遅延結果は破棄。画像は永続保存せずセッションイベントのみ保持
- [x] モックで状態遷移、クールダウン、通信障害、遅延応答、時間終了を検証
- [x] ルートからクリーンインストール。Python配布物に他機器コードが混入しない
- [x] 公式CLIのアプリ構成チェック成功
- [ ] 実機で通常作業/スマホ放置/操作/判定不能を確認
- [ ] 操作ページ・Macを閉じても単体動作する実機デモ
- [ ] 同一コミットのHF公開準備。初回公開・公式標準一覧への掲載は別途確認
