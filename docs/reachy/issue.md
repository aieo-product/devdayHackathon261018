# Reachy Mini単体の集中支援アプリと共有リポジトリからの直接配布

## 現在の仕様（2026-10-18更新）

ユーザー提供の共通API仕様に接続する。以前の本体からの直接Decisions接続・3回連続判定は廃止。
共有APIがスマホ保持5秒・しきい値・クールダウンを管理し、Reachyは撮影と自機の反応を担当する。

- API: https://focus-shared-api-20261018.take-otani.workers.dev
- 本体のみで撮影・HTTPS送信・タイマー・声/動作を継続。Mac/ブラウザの常駐不要。
- FOCUS_API_TOKENは本体の0600設定に保存。OpenAIキーを端末へ置かない。
- 生JPEG/一意X-Frame-Id/同時1件/next_capture_after_msに従う。
- 新しいフレーム応答のnotifyだけを一度消費。古い応答やcontrol/GETから反応しない。
- 一時停止/終了/設定変更でローカル観測と通知を先に停止。サーバー停止要求の失敗でも本体は停止。
- アプリ起動時に顔を起こし、待機中は小さな呼吸・アンテナ動作を続ける。動きのチェックボックスは撤去。
- 通知時に公式😨 fear1プリセットを再生し、待機動作との同時制御を避ける。アプリ停止で全動作を止める。
- src/reachy_focus / tests/reachy / docs/reachy に分離。配布契約はルートに維持し、同一GitコミットをHFへpushできる。
